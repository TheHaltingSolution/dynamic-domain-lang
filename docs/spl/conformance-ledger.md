## Interaction acceptance gaps

The following are proposed tests, not executed or newly committed acceptance cases.

1. **Priority/time/scope/zero** (O13–O16/D14): receipt100, fallback20%, CA40%, higher-priority0%, no-match/tied-top/wrong-date/title/channel/permuted rules. Require canonical rule delivery plus candidate IDs/priorities/reasons. Hand-coded if statements do not establish generic priority-table support.
2. **Lookup/Option/identity** (T16–T22/Q07–Q08): absent key/present0/present10, duplicate equal/unequal key, composite agreement/title/period near miss. Exercise all native stages, typed transport and canonical delivery.
3. **Group/join/cardinality/measure** (Q09–Q14/D21): parent receipt plus two cash applications, repeated join key and missing title. Preserve intended multiplicity, reject required one-to-one violations, never add parent+children as separate receipts; include empty groups/metadata-driven zero titles.
4. **Ordered state/tie** (Q05/Q11/Q16): A80/B80 compete for100; A-first ->80/20, B-first ->20/80. Same date without an authorized tie key fails. Use composite sort before fold, serialize/replay state; stable input order is not contractual priority.
5. **Canonical mechanism promotion** (F16/F25/F28/D26/D29): existing direct advance/reserve/payment cases gain versioned schema/profile/authority closure; preserve observation cutoff, duplicate disbursement, V1/V2 state and obligation identity. Direct bindings alone do not pass.
6. **Ratio vs monetary precision** (F02–F04): precision metadata with ratio quantum .0001 independently of USD .01; compare operation order and reject wrong unit. A ratio clause is not a currency rounding policy.
7. **Revision vs payment** (F29/U05): issued100/paid80/revised90/Q1earned30. Authorized restatement vs prospective routes both reconcile outstanding40 with different period lines; preserve originals/opening snapshot and apply each correction once.
8. **Failure/audit publication** (U18–U26): malformed amount/unmapped asset/unresolved policy/late evidence/generated error in shared pool; check raw disposition/control gap/source span/no state. Interrupt publication and reject stale completion identity.
9. **Feature freeze** (A12–A13/R16): pin supported grammar/core/schema/diagnostics/trace/profile/build/source/expected outputs, preserve old source replay, document exclusions. A policy hash change alone is not a language extension, migration or compatibility proof.
