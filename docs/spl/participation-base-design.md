# C02 participation-base controls before SPL implementation

The independent [oracle](../../oracles/participation_bases.py) starts from the
original [neutral facts](../../cases/participation-bases/neutral.json) and the
explicit [policy](../../cases/participation-bases/policy.md). It imports only
Python standard-library calendar, exact-rational, text and copying facilities.
No source, adapter, canonical runner or financial runtime was consulted to
derive these expectations. This is independent specification evidence, not
native language support or a full contract interpretation.

The first discriminator is gross125 versus net100 at20%, yielding25 versus20.
The second is quantity100 times USD1.50/Download, yielding150 before a separately
selected50% participation share gives75. Using monetary net as quantity,
selecting the wrong percentage basis, confusing ratio and money/unit rate, or
applying participation twice changes these original-fact controls.
The baseline's monetary net100 happens to equal quantity100, so separate
controls change deductions25 to45 while retaining quantity100 (unit results
stay150/75), then change quantity to80 while retaining net100 (120/60). These
asymmetric controls detect an otherwise invisible money/quantity substitution.

The source author should register four visibly named policies and retain the
original measures and rate/share identities. Native SPL must derive every
total, basis, rate application and participation result. An adapter may decode
and preserve original facts and bind typed interfaces; it must not supply
net amounts, chosen monetary answers, precomputed allocations or oracle output.
No new arithmetic primitive is proposed. Unit dimensional checking, canonical
scope/evidence admission, actual native IR and emitted execution remain
separate acceptance obligations.

Test controls cover zero/empty/fractional facts, source-row splitting and
permutation, exact Unicode identities, scope/period/cutoff near misses, unknown
populations, negative/duplicate/aliased originals, original observation order,
rate ranges and wrong unit/currency. Invalid unused originals must still block.
Fractional timestamps beyond microseconds and equivalent numeric-offset
spellings retain exact cutoff/observation semantics and original lexemes.
These are targeted finite distinctions, not a claim about every composition of
language features. Future native evidence must identify its frozen files,
effective backends, complete publication loader checks and original controls.

Source authoring then exposed two temporal admission gaps. The independent
oracle had not checked normalized UTC year bounds and unnecessarily rejected
lowercase markers supported by the existing Instant representation. The revised

or goldens. It also expressly preserves RFC3339's `-00:00` distinction: UTC is
known and local offset is unknown, rather than an unknown UTC value. The native
lexical codec's rejection of that spelling does not require narrowing these
UTC-only economics; reversible transport retains the original label and binds
the known UTC value. No local-zone inference or compiler change is involved.
