## Workload and performance disposition

The research establishes no representative per-settlement screen-industry
distribution or measured SPL throughput. Enterprise title counts, annual union
payments and first-party music-client timing disclosures use different units;
do not turn them into an SPL service-level promise.

The repository RQ-07 readable package was inspected here: seven canonical
financial facts, three evidence events and two allocation records. The response's
stored trace byte/node/edge counts describe its inspected artifacts; this update
does not independently recertify those historical artifact sizes or extrapolate
bytes per fact. Source parents, allocation rows, projected receipts, canonical
events and trace nodes require separate counters.

The listed mixture is a generator choice, not an observed production distribution.
Current record guard counts canonical financial facts and evidence events before
allocation; a benchmark generator must report which lineage records fall within
that count, avoiding conflating raw inputs with guard-counted objects. Passing
the count check does not guarantee completion within other limits. Test rule
count, match multiplicity, cost-heavy inputs, sparse 32-way tails, hot-pool skew,
rational precision and audit output independently.

Use named actual hardware, worker count, implementation pin and audit mode;
cached compiled schedules; cold and warm runs; stage latency/CPU/peak memory,
input/output bytes and trace nodes/edges. The research suggests three cold and
30 warm measurements as a starting protocol, not proof of stable tail latency.
Publish all timings/failures and confidence limitations. Request permitted
anonymous p50/p90/max close counts/topology before making external commitments.

Keep platform usage denominators, shared pools/gates, allocation parents and
correction chains within coordinated dependency scopes. Parallelism across
independent scopes is distinct from processing one hot shared scope. A pure
parallel reduction cannot violate ordered fee/state steps, rounding, error order
or logical trace. Atomic publication and retry/predecessor checks need service
support; current deterministic directories do not establish concurrency safety.
