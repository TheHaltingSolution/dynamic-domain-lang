# Native method source and audit cost

23 November 2026. Implementation guidance from retained native runs, not a new
language specification or a successful capacity claim. Keep the accepted
[readable authoring target](readable-language.md): financial rules first,
explicit incorporated policy and technical bindings. Normalized native modules
still need readable policy, original facts and independent controls.

## Preserve the calculation boundary

SPL selects terms/evidence by scope, effective date and observation cutoff and
calculates all financial intermediates. An adapter may validate physical shape,
parse exact values, enumerate original rows and transport original references.
It must not supply selected rates, release balances, paid totals, catch-up
amounts or another solved financial answer in place of the source calculation.

For every optimization compare complete outcomes and actual closing state,
including original-history and lexeme retention, unknown/preview behavior,
failures and scope. New source is a new program: equal financial outcomes do
not establish byte-identical or identical logical traces. A changed physical
state profile needs an explicit version and a specified full-state comparison.

## Use measured source changes

- Hoist a loop-invariant, total calculation into a named definition outside the
  loop. Count a decoded evidence population once rather than summing it again
  inside every evidence-row check. Check demand/error order before moving an
  operation; a lookup, division or assertion is not automatically total.
- Project only required typed fields for repeated financial/validation loops.
  Retain original full source records at explicit input/snapshot boundaries.
  Passing an entire historical source registry through every fold accumulator
  makes reference/instance/operand observations unnecessarily large.
- Use an existing unique original row identity on a transient derived wrapper
  when the trace otherwise embeds an anonymous record. Verify the relevant
  uniqueness first. Do not invent economic IDs, truncate originals or hash away
  references merely to reduce output.
- For Text identity uniqueness, an explicitly sorted adjacent fold can replace
  repeated full-population equality scans. Keep nonempty/duplicate diagnostics
  and original Text values; this is not permission to narrow Text to ASCII.
- A temporary Int slot may accelerate an exact original-reference association.
  The adapter assigns original row positions only. SPL must validate slot
  uniqueness/range, original-ID equality and all financial evidence predicates.
  A slot is not authority, identity, an evidence selection or a state key.
  Test raw native bindings with wrong/missing/duplicate slots, including slot0.
- Exact original-record JSON Text can be a physical transport representation
  only when serialization/restoration is checked against the complete originals,
  typed financial fields remain available to SPL, and the source still selects
  and pins the correct as-known prefix. Copying that Text into every hot-loop
  record can increase trace size instead of reducing it.

Keep mechanical transport choices visible in the module/interface documentation,
not hidden in a financial policy default. Evidence and raw state must continue
working with non-ASCII Text identities and exact fractional timestamps wherever
that profile already admits them. Declared Id namespaces retain their separately
specified ASCII profile.
