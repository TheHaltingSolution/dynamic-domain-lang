# Independent C13 original-fact replay controls

The [casepack](../../cases/dependent-replay/neutral.json) and
[policy](../../cases/dependent-replay/policy.md) specify the remaining finite
`B-C13-REPLAY` and prospective-attribution part of `B-C13-PROSPECTIVE` before a
separate author implements source. The original100/paid80/revised90 plus next30
requirement and full dependent suffix are drawn from the accepted0b91bc7
backlog/catalog. Synthetic cumulative-tier economics are an explicit research
assumption, supplying an actual dependent calculation rather than reusing an
independent next-period30 answer. Existing revision, Disney and AO source/oracles
were not inspected or imported for this authoring task.

API: `oracles.dependent_replay.dependent_replay(data)`; failures raise
`DependentReplayOracleError` without returning partial state or mutating inputs.
`exact_json` converts exact fractions to integer/rational strings while preserving
all original raw facts/lexemes. The oracle imports only standard `copy`,
`datetime`, `fractions` and `re`. It has no compiler, SPL, adapter, filesystem,
clock, network or existing financial implementation dependency.

The JSON wrapper `dependent-replay-casepack/1` supplies four complete neutral
factsets: simple/dependent, each with separately stated restatement/prospective
authorization. Original period/issue/receipt/term records, actual bank80,
approved applications and complete populations remain explicit. Original issue
control fields100/10 and opening/closing meters are checked against original
basis/terms; corrected90/8 or outstanding40/18 are not supplied as input answers.

non-adjustment earnings plus cumulative authorized signed correction. This
separately identifies original issued-unpaid20/30, revised original economic
unpaid10/18, current earning30/0, correction-10/-12, current recognition30/20 or
0/-12, and final40/18. No revised economic view is labeled as an actually changed
original issue, and no calculated adjustment is labeled issued or paid.

The oracle replays stored original frames to derive active replacements,
postings and consumed identities. Supplied opening totals are reconciliation
claims, not financial answers. The complete historical result snapshots are
checked before current recognition. Actual serialized successors retain original
issued records and paid80, recognize no repeat correction, and compare previous
objects unchanged. Scope/policy/research/raw-registry pins are immutable after
genesis. Neutral predecessor references are supplied original identities; this
work is not external artifact authenticity or distributed transaction proof.
